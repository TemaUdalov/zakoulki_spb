# Закоулки Петербурга

Карта необычных мест Санкт-Петербурга, которые собирают сами пользователи: дворы-колодцы, мозаики в парадных, стрит-арт, виды с неожиданных точек. Без музеев и главных достопримечательностей — только то, что не найти в путеводителях.

## Возможности

- Карта с метками и кластеризацией: при отдалении близкие места склеиваются
- Карточка места: фото, описание, теги, автор, пешеходный маршрут в Яндекс Картах
- **Ссылка на место** (`#/place/<id>`) — кнопка «Поделиться» копирует её или открывает системное меню на телефоне
- **Лайки и «я тут был»**, вкладка «Лучшее за неделю»
- **Рядом со мной:** места в радиусе 500 м – 2 км, поиск считает PostGIS на стороне базы
- **Прогулка:** собираешь до 10 мест, упорядочиваешь по пути, строишь пешеходный маршрут (OSRM) и открываешь его в Яндекс Картах
- **Комментарии** с подсказками («арка теперь на домофоне»)
- **Профиль автора:** имя, статистика, все места человека; своё имя можно поменять
- **Редактирование** своего места, включая фото и точку на карте
- Фото сжимаются в браузере, а EXIF-метаданные (координаты, модель телефона) удаляются перед загрузкой
- Вход по ссылке на почту, без паролей
- Фильтр по тегам, тёмная тема, мобильная вёрстка
- Защита на уровне базы: Row Level Security, проверка путей к фото, лимиты 10 мест и 30 комментариев в сутки

## Стек

- **Фронтенд:** React, TypeScript, Vite
- **Карта:** MapLibre GL, векторные тайлы [OpenFreeMap](https://openfreemap.org) (без ключей)
- **Бэкенд:** [Supabase](https://supabase.com) — PostgreSQL, авторизация, хранилище файлов
- **Деплой:** GitHub Pages через GitHub Actions

## Запуск

### 1. Supabase

1. Создай бесплатный проект на [supabase.com](https://supabase.com).
2. Открой **SQL Editor** и выполни по очереди два скрипта: сначала `supabase/schema.sql` (таблица мест, правила доступа, хранилище фото), затем `supabase/002_features.sql` (профили, лайки, комментарии, PostGIS).
3. В **Authentication → URL Configuration** укажи `http://localhost:5173` в поле Site URL. Когда появится демо, добавь его адрес в Redirect URLs.

### 2. Проект

```bash
cp .env.example .env   # вставь Project URL и anon/publishable key из Project Settings → API
npm install
npm run dev
```

Откроется на http://localhost:5173.

### 3. Деплой

1. В репозитории: **Settings → Secrets and variables → Actions** добавь секреты `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
2. **Settings → Pages → Source:** выбери **GitHub Actions**.
3. Запушь в `main` (вместе с `package-lock.json`). Сайт соберётся и опубликуется автоматически.

## Структура

```
src/
  App.tsx                   — состояние приложения, роутинг панелей
  components/
    PlacesMap.tsx           — карта MapLibre: слои, кластеры, маршрут, круг поиска
    PlaceList.tsx           — список мест, вкладки «Новые / Лучшее за неделю»
    PlaceCard.tsx           — карточка места: реакции, поделиться, прогулка
    PlaceForm.tsx           — добавление и редактирование
    Comments.tsx            — комментарии
    ProfilePanel.tsx        — профиль автора
    NearbyPanel.tsx         — «Рядом со мной»
    WalkPanel.tsx           — прогулка
    AuthPanel.tsx           — вход по ссылке на почту
  lib/
    places.ts               — места: чтение, запись, поиск рядом
    social.ts               — реакции, комментарии, профили
    router.ts               — роутер на хэше адреса
    walk.ts                 — маршрут прогулки (OSRM) и её хранение
    geo.ts                  — расстояния, круг на карте, порядок обхода
    image.ts                — сжатие фото и удаление EXIF
    types.ts                — типы и список тегов
supabase/
  schema.sql                — места, правила доступа, хранилище фото
  002_features.sql          — профили, реакции, комментарии, PostGIS
```

## Архитектурные решения

- **Роутинг на хэше** (`#/place/<id>`): GitHub Pages не умеет отдавать `index.html` на любой путь, а хэш-ссылки работают без настройки сервера.
- **Счётчики в представлении `places_feed`** с `security_invoker`: один запрос отдаёт места со всеми счётчиками, при этом RLS продолжает действовать.
- **PostGIS** для «рядом со мной»: координаты хранятся в колонке `geography` с GiST-индексом, расстояния считает база.
- **Триггер на запись мест** пересчитывает координаты, проверяет пути к фото и не даёт подменить автора при редактировании.
